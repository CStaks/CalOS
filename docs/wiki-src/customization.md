# Customizing CalOS

CalOS is a Fedora Atomic desktop, so customizations live in your home
directory rather than in system files.

- **Apps:** install Flatpaks from Flathub.
- **Shell & tools:** edit your dotfiles under `~/.config`.
- **Bootc layers:** `bootc container layer` can layer extra packages, but
  they're replaced on the next image update.

See the main CalOS site for the full feature list.
