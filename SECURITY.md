# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| v1.1 Huron  | :white_check_mark: |
| v1.x   | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities privately through GitHub's **Security Advisories** feature.

Do not create a public GitHub issue for security vulnerabilities.

Include a clear description of the vulnerability, the affected component or version, and steps to reproduce it.
