# Support

Thanks for using CalOS

## Questions and Help

If you need help using the project:

- Check the [README](README.md) first.
- Search existing [GitHub Issues](../../issues) to see if your question has already been answered.
- If you can't find an answer, [open a new issue](../../issues/new).

## Bug Reports

If you've found a bug, please open an issue and use our bug report template.

For more information about contributing bug fixes, see [CONTRIBUTING.md](CONTRIBUTING.md).

## Security Issues

**Please do not report security vulnerabilities in public issues.**

See [SECURITY.md](SECURITY.md) for instructions on privately reporting security vulnerabilities.

## Feature Requests

Feature requests and ideas are welcome. Please search existing issues first, then open an issue with our feature requests template.

## Community

Please keep discussions respectful and follow our [Code of Conduct](CODE_OF_CONDUCT.md).
